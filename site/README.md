# 數學圖解互動工具（國小版）

手繪筆記風的圖解互動網站。純 HTML / CSS / JavaScript，直接開 `index.html`（需連網載入字體）。

## 新增一個單元＝只新增一個檔案
1. 複製 `units/_template.js`
2. 改名為 `<年級><u上/d下>-<章>.<節>.js`，例如：六下 5.3 → `6d-5.3.js`、五上 9.2 → `5u-9.2.js`
3. 完成。首頁會自動偵測並打勾；標題、章節、上一節／下一節都從 `catalog.js` 自動帶入。

章節目錄在 `assets/js/catalog.js`，每章一行，編號自動產生。要補一、二年級，照格式加一個學期即可。

## 結構
- `index.html`：首頁（年級分頁、學期目錄、已完成打勾）
- `unit.html`：所有單元共用的頁面，用 `unit.html?u=6d-5.3` 載入對應檔案
- `assets/js/core.js`：SVG 手繪工具與角色、主題切換（淺色／深色／系統）、單元樣板 `NB.unit`
- `assets/js/solid.js`：純 SVG 3D 引擎（可拖曳旋轉），提供 `cuboid`、`grid`、`prism`
- `assets/js/catalog.js`：目錄
- `assets/js/home.js`：首頁
- `units/`：每個單元一個 `.js`

## 數學式（KaTeX）
- 文字裡用 `$...$`（行內）或 `$$...$$`（獨立一行）寫 LaTeX，例如 `"面積 $=\\frac{1}{2}\\times a\\times h$"`
- 沒加 `$` 的算式（含 × ÷ ＝ + 分數 π ²）會自動轉成 LaTeX；轉得不理想時，用 `$...$` 明確包起來
- 適用：`q`、`steps`、`ch.q`、`ch.h`、`eq.innerHTML`；SVG 裡的文字（`NB.t`）不支援
- KaTeX 放在 `assets/vendor/katex/`（目前只含 Main-Regular 字型；要完整的斜體變數、大型符號，請換成官方完整 fonts）

## 圖形清晰度
全站 SVG 不再套用濾鏡（濾鏡會讓整張圖先點陣化而變糊），卡片也不再旋轉。需要手繪感請用線條端點圓角、手寫字體與歪斜邊框。

## 無限出題（drill.html）— 免費、不用登入、不用後端
和學員專區完全分開：不載入 member.js、不呼叫 Cloudflare Worker，題目全部在瀏覽器裡用亂數產生。
- 網址：`drill.html#print`（列印練習卷）、`#online`（線上練習）、`#log`（練習紀錄／錯題本）
- 題型產生器：`assets/js/drill-core.js`（亂數、空格格式、批改、SVG 圖形）＋ `drill-g12.js`／`drill-g34.js`／`drill-g56.js`（依 catalog.js 的 412 個小節，各有基礎／標準／挑戰三種難度）
- 介面：`assets/js/drill.js`、`assets/css/drill.css`
- 卷號：同一個卷號＋同樣設定＝一模一樣的卷；「複製分享連結」會把單元、難度、題數、卷號都放進網址
- 紀錄只存在瀏覽器（localStorage `nb-drill-rec`），不上傳
- 新增或修改題型：在對應年級檔案裡 `DR.def("5u-6.1", function (R, lv) { return { q: "題幹 [?]", b: [DR.N(答案, "單位")] }; })`
  - 空格：`DR.N` 數字、`DR.F`／`DR.FA` 分數（預設要最簡、假分數要寫成帶分數）、`DR.S([選項], 答案)` 選一個、`DR.mc(R, 題幹, 正解, [錯誤選項])` 選擇題
  - 改完在專案外跑 `node gen-test.js` 之類的檢查：每個產生器跑幾百次，確認答案能通過自己的批改

### 直式、圖形與題型（第二版）
- `drill-vert.js` 直式引擎：題目帶 `calc: { op: "+"|"−"|"×"|"÷", a: "12.5", b: "3.75", rem: 1, tz: 1 }` 就會自動排出直式；答案卷寫出進位、退位（劃掉原數字）、部分積、長除法每一步。可設定「已列好／自己列／只要橫式」、虛線方格、位值標示、進位小格
  - 位值標示（個、十、百／十分、百分）在加、減、除都跟著小數點走。**小數乘法不標位值**：小數乘法是先靠右對齊當成整數算、最後再點小數點，欄位不等於位值（2.4×3 的「3」會排在十分位那一欄），硬標會標錯
- `drill-fig2.js` 圖庫：長方體（虛線隱藏邊、尺寸標示線）、水箱水位與排水法、角柱角錐、圓柱圓錐球、積木堆、L 形組合體、挖洞形體、展開圖；線段圖、相遇追趕、流水、三角形角度、對稱方格、百格圖、十格框、分合圖、積木、時間軸、短除法、樹狀圖……
- 題目欄位：`fig` 題目一定要的圖、`aid` 解題小幫手（可設定題目卷也附／只在答案卷／不附，也能各單元分別開關）、`figFn(md)`／`aidFn(md)` 題目卷和答案卷畫法不同時用
- `drill-more.js` 其他題型：`DR.more("5u-6.1", "應用題", function (R, lv) {…})`。同一小節的題型會輪流出現，老師可以在「各單元分別設定」只留想要的題型
- 分享連結有版本號 `ver=2`，並寫出每個單元用哪幾種題型；以後新增題型，舊連結出的卷也不會變。沒有 `ver` 的連結（第一版）會只用基本題重現
- 填滿 N 頁：題數一題一題試排，留下放得下的最多題數；自動欄數在大部分是直式時排 3 欄；直式格子有大中小三種
- 卷面修改：每題可以換題、改字、刪除；還能「加一題」「自己出一題」、各單元自訂題數。換題、刪題、加題、題型和各單元設定都會放進分享連結（改字與自訂題不會）

## 遊戲場（games.html）— 六個小遊戲，一樣不用登入、不用後端
題目直接用無限出題的產生器，所以 412 個小節都玩得到；成績、印章只存 localStorage（`nb-games`），換裝置就沒有了。
- 網址：`games.html`（大廳）、`#fix` 修補計算機、`#hunt` 錯誤獵人、`#card` 島民挑戰卡、`#race` 快速反應賽、`#teach` 我是出題老師、`#match` 概念配對、`#play?…` 別人分享的卷
- 檔案：`assets/js/games-core.js`（共用引擎）、`assets/js/games.js`（六個遊戲）、`assets/css/games.css`。頁面要同時載入 `drill.css`（選範圍沿用無限出題的樣式）和 `qr.js`（分享卷的 QR）
- **錯答引擎**是核心：`GM.wrongs(Q)` 針對每一題做出「學生真的會犯」的錯答，每一個都附原因（忘記進位、不夠減就大減小、只乘了個位沒補 0、餘數算成還差多少、分母也跟著加進分子、小數點點錯位置……）。修補計算機、錯誤獵人、快速反應賽的假答案全部由它產生，所以不必另外寫題庫
- `GM.recalc(Q, a, b)`：題目帶 `calc` 的可以讓學生自己改數字，答案和直式跟著重算（我是出題老師用）
- `GM.encode/decode`：把整張卷（每題的小節、卷號、題型、改過的數字）塞進網址，同學點連結就能作答
- 各遊戲吃得到的小節：挑戰卡／出題老師 412 個全部；錯誤獵人 406；修補計算機 384；快速反應賽 362；概念配對 327。湊不出題目的小節（多半是一、二年級的圖形分類、面積直接比較）會跳出提示請人換範圍或換遊戲，不會當掉
- 改完題型或引擎後，建議用 node 載入這幾個 js 跑一輪檢查：錯答不能等於正解、各遊戲的覆蓋率、改數字重算、分享連結來回

## 漢堡選單（navmenu.js）

## 小額贊助（BobaMe）
`assets/data/config.js` 的 `donate.url` 填入你的 BobaMe 頁面網址（例如 `https://你的帳號.bobaboba.me/`）。
填了之後，漢堡選單、所有頁面的頁尾、島覽頁最後一區會出現「請島民喝珍奶」按鈕；空字串就全部隱藏。
