政策蘇昊數理「數光島筆記本」隱私權政策

蘇昊數理（以下稱「本站經營者」）依「個人資料保護法」及相關法令，訂定本政策，說明「數光島筆記本」網站及其相關服務（以下稱「本服務」）蒐集、處理及利用個人資料之方式，以及使用者所享有之權利。使用者登入或繼續使用本服務，即表示已閱讀並同意本政策及使用者條款。

使用者未滿十八歲者，其訂購、付款及使用，均應由其法定代理人（家長或監護人）閱讀並同意；逕行使用本服務者，視為已取得法定代理人之同意。

施行日期：2026 年 10 月 24 日

壹資料之蒐集

第一條（蒐集之個人資料類別）

  1. 本服務蒐集之個人資料如下：
    1. 登入資料：使用者以 Google 帳號登入（Firebase Authentication）時所提供之電子郵件地址及顯示名稱。本站經營者無從取得使用者之 Google 密碼。
    2. 班級名單資料（由授課教師登記）：班級、座號、姓名、年級、身分（學生或教師）及使用期限。
    3. 學習紀錄：作答結果、作答時間、積分、等級、勳章、錯題、每日一題、小測驗、模擬考試成績，及教師指派測驗之完成狀況。
    4. 模擬考試紀錄：成績、用時，以及離開作答頁面之次數與累計秒數。
    5. 列印紀錄：使用者列印練習卷時之時間、電子郵件地址、班級座號姓名、IP 位址、網路業者名稱、大略所在地（國家及城市，由 Cloudflare 判斷）、瀏覽器與作業系統、裝置型號（以瀏覽器提供者為限）、螢幕大小、時區、語言、卷號，及該份練習卷之題目。
    6. 問題回報：使用者送出之內容與類別、至多三張附圖，以及電子郵件地址、班級座號姓名、當時之頁面網址、瀏覽器與裝置資訊、螢幕大小及近期之錯誤訊息。
    7. 訂購與付款資料（購買付費方案時）：您透過官方 LINE 帳號洽詢時之 LINE 顯示名稱、對話內容；訂購人姓名、聯絡方式、欲開通之 Google 帳號電子郵件；訂購之方案、期間、金額；付款日期、轉帳帳號後五碼或匯款資料；發票或收據抬頭及統一編號（如需要）；退款申請及處理紀錄。本服務不蒐集、不儲存信用卡號。
    8. 連線資料：網站及雲端服務（GitHub Pages、Cloudflare）於正常運作時所記錄之 IP 位址等技術資料。
  2. 使用者裝置上之本機儲存資料：主題、注音、列印設定及登入狀態等，儲存於使用者瀏覽器之 localStorage 及 sessionStorage，僅用於記憶偏好及維持登入，不用於追蹤。使用者得隨時清除瀏覽器資料予以刪除。
  3. 本服務不蒐集身分證統一編號、出生年月日及定位資料，亦不主動蒐集電話與住址（除非您為開立發票、寄送文件而自行提供），亦未使用廣告或流量分析工具。

第二條（蒐集之目的）

  1. 提供數學學習、測驗、成績及學習分析，並使教師得以瞭解班級學習狀況及指派測驗。
  2. 帳號驗證與管理，確認使用者為班級名單內之學員或已購買方案之使用者。
  3. 訂購處理、帳號開通、使用期限管理、到期與續約提醒、對帳、開立發票或收據、退款及客戶服務，並依法令保存會計及稅務憑證。
  4. 維護試卷及題目之公平與保密：以出卷與模擬考試之紀錄、浮水印及離開紀錄，於試題外流時追查來源，並供教師參考。
  5. 網站安全、故障排除、系統維運，及處理使用者之問題回報。
  6. 本站經營者不將個人資料用於廣告、行銷或販售，亦不為前列以外之目的而利用。

貳資料之利用與保存

第三條（資料之檢視與提供）

  1. 使用者本人：得檢視自己之學習紀錄。
  2. 班級教師：僅得檢視所授班級學生之名單、學習紀錄、模擬考試及列印紀錄。
  3. 購買人（學校或補習班）：其所購買方案之名單與使用期限；除授課教師依前款得檢視者外，不得檢視學生之學習紀錄。
  4. 本站經營者：為維運、處理問題及管理名單之必要，得檢視全部資料。
  5. 同班同學：排行榜向同班同學顯示姓名、等級、積分、答對題數及勳章數，不顯示電子郵件地址、IP 位址或其他資料。
  6. 除前述情形及下列各款外，本站經營者不將個人資料提供予第三人：法律明文規定；配合司法機關或主管機關之合法調查；為保護使用者或他人之重大權益所必要；經使用者或其法定代理人同意。

第四條（保存期間）

  1. 班級名單、學習紀錄、積分與勳章：保存至授課教師或本站經營者刪除為止；學期結束或離班後將予刪除，使用者亦得請求授課教師隨時刪除。
  2. 訂購與付款資料：依商業會計法、稅捐稽徵法等法令所定之憑證保存期間（原則上為五年）保存，期滿後刪除；其中 LINE 對話內容於服務關係結束且無爭議後，得予刪除。
  3. 使用期限屆滿且未續約者：學習紀錄保留九十日，逾期未續約得予刪除（參見使用者條款）。
  4. 作答明細、列印紀錄、模擬考試紀錄：保存約一百八十日後自動清除；授課教師得提前刪除。
  5. 作答中暫存之題目：保存約二日。
  6. 問題回報（含附圖）：處理完畢後，由本站經營者刪除。
  7. 因法令規定或維護安全之必要而須保存者，不在此限。

第五條（儲存地點與跨境處理）

本服務資料儲存於 Cloudflare（Workers 及 D1 資料庫），網站頁面託管於 GitHub Pages。上述雲端服務之伺服器所在地由服務提供者決定，可能位於中華民國境外，本站經營者無法保證資料僅於境內處理。

第六條（第三方服務）

  1. 為提供本服務，下列第三方服務將處理部分資料，並各自適用其隱私權政策：
    1. Google：Firebase Authentication（登入驗證）及 Google Fonts（字體）。
    2. Cloudflare：後端程式、資料庫及網路服務。
    3. GitHub：GitHub Pages（網站頁面託管）。
    4. Resend：將使用者送出之問題回報通知寄送至本站經營者信箱。
    5. LY Corporation（LINE）：官方 LINE 帳號之洽詢、訂購溝通及到期通知。
    6. 銀行：您以轉帳付款時，銀行依其規定處理轉帳資料。
    7. cdnjs 及 jsDelivr：提供數學公式及注音功能所需之函式庫。

參當事人權利與資料安全

第七條（當事人之權利）

  1. 依個人資料保護法第三條，使用者就其個人資料得行使下列權利：
    1. 查詢或請求閱覽。
    2. 請求製給複製本。
    3. 請求補充或更正。
    4. 請求停止蒐集、處理或利用。
    5. 請求刪除。
  2. 使用者得向授課教師提出，或使用登入後頁面右下角之「回報問題」功能提出，本站經營者將於合理期間內處理。必要時，本站經營者得先確認提出請求者之身分。
  3. 因法令規定或執行教學、維護安全所必須保存之資料，本站經營者得不予刪除，並將說明理由。
  4. 使用者得選擇不提供個人資料；惟不提供登入及名單所需之資料者，將無法使用須登入之功能。

第八條（資料安全措施）

  1. 網站與後端全程以 HTTPS 加密傳輸。
  2. 依使用者身分（學生、教師、管理員）控管存取權限，教師僅得存取所授班級之資料。
  3. 小測驗及模擬考試之答案，於使用者送出或交卷前，僅存放於伺服器端。
  4. 使用者閒置一定時間後自動登出；練習卷及模擬考試畫面附有浮水印。
  5. 網際網路無絕對安全之方法。發生足以影響使用者之個人資料外洩事件時，本站經營者將儘速處理，並依法通知。

肆附則

第九條（政策之修訂）

本站經營者得因服務內容或法令變更而修訂本政策，修訂後之內容公布於本頁面，並更新施行日期。

第十條（聯絡方式）

使用者對本政策有任何疑問，或欲行使前述權利，得使用「回報問題」功能，或洽詢授課教師。
